# Inventario Multiorganización — Offline First

Aplicación web ligera para gestionar inventarios de múltiples organizaciones. Permite iniciar sesión, consultar el catálogo de productos (solo lectura para usuarios de empresa), filtrar por división y agregar comentarios a cada ítem. Funciona sin conexión a internet: los comentarios se guardan localmente y se sincronizan automáticamente al recuperar la red.

Desarrollada con HTML5, JavaScript vanilla (ES Modules), Bootstrap 5, IndexedDB nativo y Google Apps Script / Google Sheets como backend.
